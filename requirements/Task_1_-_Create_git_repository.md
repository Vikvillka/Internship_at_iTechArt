## Task description

Create a new private repository on GitHub. 
Add https://github.com/AllekseyLeonov to the list of contributors to support pull request and review functionality.

For each task, create a pull request from the task branch to the development branch. Create the two branches and a pull request for the first task. Include the .md file with the requirements in a separate folder. For all subsequent tasks, include the relevant file to this folder in your pull request.
